# 简易购物系统（单文件版）

一个纯 Python 标准库写的命令行购物程序：注册登录、浏览商品、购物车、学生九折结算、订单查询。
**零第三方依赖**，一个 `shop_app.py` 就是全部代码。

## 运行

需要 Python 3.8 及以上（开发环境用的 3.13 / 3.14）。

```bash
python shop_app.py
```

Windows 上装了 py 启动器的话：

```powershell
py shop_app.py
```

PyCharm：打开文件 → 右键 → Run。不需要任何额外配置。

## 自检

```bash
python shop_app.py --selftest
```

会跑 11 项断言，覆盖算钱规则和“失败时数据不能被改动”这类边界情况。全部通过返回 0，有失败返回 1，可以直接当 CI 用（见 `.github/workflows/selftest.yml`）。

## 功能

- 注册 / 登录（密码加盐 SHA-256 存储，不存明文）
- 商品列表（6 样商品，带库存）
- 购物车：加购、改数量、删除
- 结算：学生九折、余额校验、减库存、出小票
- 我的订单

## 几个刻意的设计

- **金额全部用「分」的整数**，不碰浮点数，避免 `0.1 + 0.2` 那类误差
- **折扣四舍五入到分**，用整数运算 `(金额 * 10 + 50) // 100`
- **先全量校验，再统一改数据**：余额不足或库存不足时，余额、库存、购物车一个字节都不动
- **订单保存价格快照**：商品事后改价，历史订单金额不变
- **加购时拦超量**，不用等到结算才报错

## 数据

首次运行会在同目录生成 `shop_data.json`，删掉它即恢复出厂状态（100 元余额、6 样商品）。

该文件已写进 `.gitignore`——里面有密码哈希和订单记录，不应该提交到仓库。

## 换界面

业务逻辑（`Store` 类）完全不碰输入输出，想换成 Tkinter、Flask 或 Streamlit，只需要重写 `App` 那一层。
